

# 📚 StudySmart

StudySmart é um aplicativo Android desenvolvido para ajudar estudantes a organizar suas sessões de estudo e melhorar a produtividade.

O aplicativo permite criar sessões de estudo, acompanhar o tempo dedicado ao aprendizado e manter um registro organizado das atividades.

---

## ✨ Features

- Create and manage study sessions
- Track study time with a built-in timer
- Organize sessions by subjects
- Background notification system
- Persistent local data storage

---

## 🛠 🛠 Tech Stack


- Kotlin
- Jetpack Compose
- MVVM
- Navigation Compose
- Material 3
- Room with Multiple Entities
- Dependency Injection with Dagger Hilt
- Material
- Study Session Timer
- Android Notifications
